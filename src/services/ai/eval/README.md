# Spatial analysis evaluation

Run `npm run eval` (or `npm.cmd run eval` on Windows) to replay the deterministic spatial analyzer against two separate tracks:

- **Synthetic stress suite** (`evalDataset.ts`): authored box geometry used to exercise room labels, perspective-like box layouts, low-confidence/low-light cases, missing and extra detections, invalid boxes, and ambiguous overlaps. These fixtures are not photographs, do not test image understanding, and must not be reported as real-world performance.
- **Real-photo track** (`real-photo-manifest.json`): licensed or user-consented room photos with independently annotated objects and relations, paired with a saved output from the existing vision model. This track is empty until qualifying images and annotations are added. The runner reports no real-photo metrics while it is empty.

Keep approved real images under the ignored `eval-data/real-photos/` directory. Do not commit personal room photos. For each image, add a manifest case with its SHA-256, source/rights record, room, camera angle, lighting, difficulty notes, two independent annotation reviews, model identifier and capture time, ground-truth boxes, captured detections, and expected spatial relations. Ground-truth relation `objectIds` refer to `groundTruthObjects`; predicted relation matching is by relation type and normalized object labels. Record each box in normalized 0-100 image coordinates. Reviewers should label all in-scope objects and relation expectations before comparing them with model outputs, so missed objects and findings remain measurable.

The report gives relation precision/recall/F1, false and missed findings, evidence-status accuracy, unsupported-statement rate, object-box match counts, mean IoU and the proportion of labeled boxes at IoU >= 0.50. Per-relation runtime is the average whole-case analyzer time for cases containing that relation type; it is not the isolated cost of that relation. “Unsupported statement” means a prediction does not match a labeled relation, does not cite the boxes of both referenced detections, omits limitations, or asserts `Potential Concern` where that status is not labeled. Runtime measures only the deterministic spatial analyzer over saved detections; it is not model latency or end-to-end scan time.

The current repository's pre-annotated demonstration assessments are deliberately excluded from the real-photo track: their source rights and independent ground truth are not documented. A non-empty track is still a small, bounded evaluation set, not proof of generalization to all homes, users, or camera conditions.
